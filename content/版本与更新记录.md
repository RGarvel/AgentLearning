## 二、0.24.0 → 0.25.0 到底改了什么

### 公开 API 变化（以 `repo/tests/fixtures/released_api_contract.json` 差分核对）

| 变化 | 具体内容 | 影响面 |
| --- | --- | --- |
| 新增会话适配器工具 | `agents.memory.await_session_mutation`、`coerce_session_settings`、`resolve_session_limit` | 只影响"自己实现 `Session`"的人 |
| 交接错误恢复（opt-in） | `handoff(...)` 与 `Handoff` 新增 `failure_error_function`（默认 `None` = 异常照抛） | 多智能体编排的失败降级策略 |
| 压缩会话默认模型 | `OpenAIResponsesCompactionSession(model="gpt-6-luna")`（原 `gpt-4.1`） | 长对话压缩行为对齐文档 |
| Trace 记录工具定义 | `generation_span(..., tools=...)`、`GenerationSpanData.tools` | 模型调用的 trace 里能看到当轮工具清单 |
| 模型默认参数钩子 | `Model.get_default_model_settings()`；"隐式默认值 vs 显式赋值"的区分修正 | 自定义 `Model` 实现与默认参数推导 |

### 非公开/内部变化

- `run_internal/items.py`：孤儿工具调用清理新增 `preserve_pending_async_calls`，恢复 `RunState` 时保留挂起的外部异步调用。
- `run_internal/run_loop.py`、`turn_preparation.py`：`get_model_settings(...)` 现在会带上 `prompt` 与 `has_tools`，供模型侧推导默认参数。
- `model_settings.py` / `default_models.py`：默认参数从"拷贝整块预设"改为"按字段判断是否为隐式"，同时把 GPT-5 及更新模型的判断从硬编码列表改成正则。
- 沙箱移除了 Runloop provider；依赖版本整体上浮（openai 3.48、mcp 2.3、starlette 等）。

> 一个值得注意的事实：**`docs/` 在本版没有任何改动**。0.25.0 主要是让代码追上文档已描述的行为（压缩默认模型、交接错误恢复、generation span 的工具字段），因此课程中原本按文档写的这些约定，反而在 0.25.0 里"变成真的"了。

## 四、下次怎么更新（可复现流程）

```bash
# 1) 取新快照（保持 repo/ 为当前基线）
curl -L -o repo.zip https://codeload.github.com/openai/openai-agents-python/zip/refs/heads/main
unzip -q repo.zip && mv openai-agents-python-main repo-new

# 2) 先看变更范围
diff -rq repo repo-new | grep -v '^Only in repo/tests'   # 文件级
sed -n '1,40p' repo-new/CHANGELOG.md                      # 发布说明

# 3) 公开 API 差分（最权威）
python - <<'PY'
import json
old = json.load(open("repo/tests/fixtures/released_api_contract.json"))
new = json.load(open("repo-new/tests/fixtures/released_api_contract.json"))
o, n = old["callables"], new["callables"]
print("added:", sorted(set(n) - set(o)))
print("removed:", sorted(set(o) - set(n)))
# 逐项比较参数名与默认值，见课程第 2 章"跟进上游版本"
PY

# 4) 换基线并重建
rm -rf repo && mv repo-new repo
```

**更新时的判断顺序**

1. 公开 API 有变化 → 必须改对应章节 + 更新速查表（第 32 章）；
2. 只有 `docs/` 变了 → 优先核对概念章节，源码章节可后置；
3. 只有 `src/` 变了 → 检查第 27-29 章引用的行号与函数名；
4. 发布说明里出现 breaking change → 在对应章节加"迁移"提示，并提升课程基线号。

**验收清单**

- [ ] 所有 `from agents...` 导入仍能解析（模块与符号都存在）；
- [ ] 第 32 章的参数表与 `released_api_contract.json` 一致；
- [ ] 第 17/19/22 章的新增能力已覆盖；
- [ ] 版本号（README、第 0/2/19 章）与 `repo/pyproject.toml` 一致；
- [ ] 重新汇编合集并检查目录含 33 章。
